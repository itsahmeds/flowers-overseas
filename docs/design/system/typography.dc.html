Typography · [internal]
Purpose
The type ramp as drawn: every step at both artboard sizes, its line height and tracking, the measure, and the four scripts the two shipped families must cover.
Pairing
Newsreader 500 for the display voice (headings and the wordmark) and IBM Plex Sans 400/600 for everything else — the founder-approved pairing. Both are self-hosted, subset to latin-ext, and named only by --font-display / --font-body; no component names a family.
Fluid vs fixed
In code each display step is a clamp() whose floor is the 390 artboard size and whose ceiling is the 1440 one, so a headline needs no breakpoint utility to stop overflowing a phone. An artboard is drawn at one end of that clamp, which is why artboards are 1440 and 390 and nothing between.
Weight
Two faces ship (400, 600) because a third breaks the 45 KB font budget, so the canvas's “medium” resolves to 600 through --font-weight-medium rather than being matched down to 400.

Measure

--measure: 68ch

Every run of prose is capped at 68 characters. This paragraph is exactly that wide, and the same value generates max-w-prose, so the token and the utility cannot drift. Legal pages, blog posts and help answers use the prose container; a grid cell's copy inherits the cell instead.

68ch measured in IBM Plex Sans at 15 px is about 620 px, which is why the narrow container (560 px) is the one used for a single-column form and prose for text.
