Colour and contrast · [internal]
Purpose
The palette and, below it, the declared contrast manifest: every foreground/background pair a component is allowed to use, with the WCAG 2.1 threshold that applies to it.
The single source of the numbers
The manifest lives in src/modules/ui/tokens/contrast.ts and tests/unit/contrast.test.ts computes each ratio from the tokens in src/app/globals.css, in OKLCH, clamped to the display gamut. No ratio is written down here, because a written ratio goes stale and a computed one fails the build. Adding a component that needs a new pair means adding it to the manifest, which means passing the test.
Decorative, with a reason
Two pairs are declared decorative and assert no threshold; each carries a written reason in the manifest. That keeps the manifest complete — every colour token appears in it, which is itself asserted — without shipping a silent exception.
No dark mode in Phase 0
color-scheme: light is declared explicitly so form controls and scrollbars are not rendered dark on a light page. The names are semantic, so a later prefers-color-scheme: dark block is one addition to globals.css and zero component edits.

Rules that the palette exists to enforce

RuleHow it is enforced
One colour literal in the whole repositorysrc/app/globals.css's @theme block. fo/no-raw-color bans hex, rgb, hsl and oklch colour literals in components; Stylelint bans them in every colour declaration. A founder palette swap is one diff, re-running the contrast test and the visual baselines, and touching no component.
Nothing is conveyed by colour aloneA chip's word carries its status; a field error carries a message linked by aria-describedby; an accent link in prose keeps its underline.
One accentForest green, hue 155. --color-accent-strong is the pointer state — a darker instance of the same hue rather than an opacity, so its contrast with the button label is a manifest pair and not an accident of what happens to be behind it.
No photograph we do not haveEvery image slot renders the --color-photo gradient with a caption. There is no placeholder <img> and no stock photo.
