Purpose
Every primitive the v2 artboards use, at every state, drawn from system/tokens.css. Implementers build these in src/modules/ui and render the same content at /dev/components.
Status
The sheet leads the code until the v2 implementation tasks land: the README's “Where the sheet and the code currently differ” has the row. Every v1 enum is mapped here (buttons, chips, photo ratios, icons, grid sets, gaps, widths) so nothing in code is left without a drawing.
Sweep 2026-10-04
The last group, “First screens”, is proposed and not in code: hero registers, the lead photograph with its price tag, the destination postmark, three stamp sizes, the destination stamp, the plant label and pull line, and the language popup.
New primitives
Sentence picker · stamp · postmark · airmail edge · P.S. aside · note card · printed card preview and field · status chip · facts list (was spec 007's “fact list”) · picker note. Spec 009's group (date picker, date chip, tier selector, add-on row, summary, gallery) is redrawn here in v2.
Accessibility
Every control ≥ 44 px. Focus is one ring everywhere: --focus-ring (poppy, 2.5 px) at --focus-offset. Selection is shape + colour (inset ring, dot, fill), never colour alone. Motion: only the card photo's 1.035 scale and the stamp's lift, both off under prefers-reduced-motion.

A letter that is a GET form
