Components · reference sheet · [internal]
Purpose
The reference sheet for every primitive src/modules/ui ships, at every state the code can reach. It is the same surface as /dev/components (spec 004 §2's gallery, ENABLE_DEV_UI=true, noindex, refused in production) drawn as an artboard so it can be reviewed on the canvas without running the app.
In step with code
Every variant, tone, ratio, size and state below is an exported member of src/modules/ui — BUTTON_VARIANTS, BUTTON_SIZES, BUTTON_STATES, CHIP_TONES, PHOTO_RATIOS, DISPLAY_SIZES, TEXT_SIZES, TEXT_TONES, GAPS, CONTAINER_WIDTHS, ICON_NAMES, MIRRORED_IN_RTL. Nothing on this sheet is missing from code and nothing in code is missing from this sheet; see docs/design/README.md § “Keeping the sheet and the code in step”.
Specified, not yet shipped
Three groups are the exception to the sentence above and say so on themselves: Country-page blocks (spec 007), Listing and card blocks (spec 008) and Product and date-picker blocks (spec 009). Those nineteen drawings are taken from the approved spec before /plan-tasks splits it, which is the order CLAUDE.md requires — artboards precede tasks. They are not exports of src/modules/ui today, and the implementer who builds them adds them to this sheet and to /dev/components in the same pull request; until then this group is a specification and every other group on this sheet is a mirror. Nothing here invents a token: all six are built from Chip, Stack, Grid, Text and the existing space, rule and ink scales.
Copy on the sheet
Developer-facing state and token names, plus the gallery's own sample strings from src/app/(dev)/dev/components/catalog.ts. These are deliberately not message keys — a translated “disabled” would make the sheet lie about the code it documents.

FAQ list

How many flowers should I send?

An odd number. Even-numbered bunches are for funerals and for graves in Poland, so a bouquet of ten says something nobody means to say.

Which flowers should I avoid?

Chrysanthemums. In Poland they belong on graves, and sending them to someone's home reads as a funeral tribute.

the rules
RuleWhat it means here
Two actionsContinue (a real <a href> to the same page in the other locale) and Stay. No dismiss, no close cross: a third way out would record nothing and ask again.
Equal weightBoth controls wear .btn.secondary.sm. Neither answer is dressed to win.
Language of each lineThe offer carries lang for the language it offers; the Stay line has none, because it is already in the language of the page.
KeyboardFocus moves to Continue on open and returns where it was on close. Esc records Stay. The trap and the top layer are the browser’s, not ours.
NeverNo redirect, no second document, no bot branch, no cookie set by a page response, no layout shift. Every locale keeps its own crawlable URL.
