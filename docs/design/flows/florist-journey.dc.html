Florist journey · landing → first order · [internal]
Purpose
The other side of the shop: how a Warsaw florist meets us, applies, and sees their first order. This is the flow the 16 October demo walks a florist through, so the florist inbox is a real screen even though it is seeded data behind a password.
Why it matters more than it looks
Phase 0's exit signal is “≥3 Warsaw florists verbally committed after seeing the demo”. The florist's journey is therefore a Phase 0 product, not a Phase 2 portal — but only these four screens, and the inbox is a mock.
What is honest here
No florist testimonials, no shop logos, no “200 florists in 7 countries”, no payout figures presented as averages. Live stats render as a Placeholder bar until real florists exist; the payout example is labelled as an example with its own arithmetic shown.
