Consent and locale
Purpose
The three overlapping surfaces of the first visit — the locale chooser, the language-suggestion banner and the consent sheet — with their states and their z-order. They are drawn together because they are the only elements in the design that can be on screen at the same time.
The rule they exist to keep
No IP redirect. Ever. (ADR-0006) A visitor's language is never decided for them: / lists the locales, an Accept-Language mismatch is a dismissible suggestion, and the chosen locale is in the URL. Currency is a cookie; the destination country is in the shop URL.
Z-order
--layer-header 100 (sticky header) < --layer-banner 200 (locale suggestion) < --layer-overlay 300 (consent sheet, and the skip link when focused). Named tokens, so the three cannot fight.
Copy status
chooser.*, banner.* and a11y.* exist in messages/en.json and are quoted verbatim below. There are no consent.* keys yet — every string on the consent sheet is marked [slot] and is owned by the spec that ships it.
Owning spec
003 (locales, chooser, banner) · 004 (layers, chrome) · consent sheet and settings: not yet specified — see docs/design/README.md

Copy
None exists. Every string is [slot] until the owning spec writes consent.* keys.
Rules it must keep
Reject is as easy to reach and as prominent as Accept; nothing non-essential is set before a choice; the choice is logged with its version; re-openable from the footer's “Cookie settings” link, which already exists as footer.cookieSettings.
Focus
Focus moves into the sheet, is trapped while it is open, and returns to the trigger on close. The skip link shares this layer so a keyboard visitor is never behind it.

—Z-order and first-visit sequence
layer-overlay · 300Consent sheet · the focused skip link. Dismissible, focus-trapped, above everything.
layer-banner · 200Locale suggestion. Pushes nothing, blocks nothing, remembers its dismissal.
layer-header · 100Sticky header. scroll-padding-block-start keeps a focused anchor target clear of it (WCAG 2.4.11).
pageEverything else. No component writes a raw z-index.
Land on / or a locale page→ Consent sheet (first visit only)→ Locale suggestion, if the language does not match→ The page, in the locale that is in the URL

The order is deliberate: consent is asked before anything optional loads, and the language question comes after, because switching language must not throw away a consent choice. Neither surface may be the reason a crawler sees different content — both are additive to a fully server-rendered page.
