Admin · country detail · desktop 1440 · spec 012b · [internal]
Purpose
One country: what the go-live check reads, exactly which conditions are unmet, and the switch with its typed code (spec 012b §2.8). For a live country the same check runs read-only and lists what no longer holds; the rollback is back to demo. Desktop: the facts on two thirds; the go-live card sticky on the last third.
URL
/admin/countries/{iso2}
Index
Never: X-Robots-Tag: noindex, nofollow and Cache-Control: no-store, private on every /admin response, <meta name="robots" content="noindex,nofollow">, Disallow: /admin/, no sitemap, no public link (spec 012 AC-5, AC-6; spec 012b AC-26). No locale prefix. Ids and SKUs, never names, in URLs.
Permission
country.status (admin) for Go live and Back to demo; other roles see the check with no buttons and the line “Only an admin can change the status.”
Writes
setCountryStatus (CountryStatusFlipSchema, typed code required) inside withAdminContext; spec 012’s status_flip_guard() refuses any other path. Sets first_live_at once, calls invalidate() once with country:PL, corridor:PL, catalog:PL, hub:{locale} and home:{locale} for every locale, sitemap, and requests a publish exactly when the existence diff is not empty (AC-25). live → demo returns pages to noindex,follow and out of the sitemaps within 60 s. live → disabled is refused (§13 Q10).
Preflight
goLivePreflight(iso2) → PreflightResultSchema, one named reason per unmet condition: operations complete; vat_rate_bp and supply_model set; at least one active, non-demo florist with coverage; at least six (PRODUCT_COUNT_FLOOR) active products with an open price, an approved main photo, and saleable by saleable_offer; a reviewed en corridor text in its live state; not on the sanctions list (plan/07 §9).
Not here (later)
The operations form (zone, cutoff, delivery days, Sunday rule), holidays and the guide and country-page switches: founder default to §13 Q16, after the first sale. They are drawn read-only, with a “Later” line, and no edit control.
The two inputs
Amendment A-orchestrator-2026-10-20a (PR 298): in the preflight’s missing state, exactly two inputs, each present only while its stored value is null: VAT rate (vat_rate_bp, an integer 0 to 10 000) and supply model (supply_model: principal or agent), plus a required reason naming the accountant’s answer, stored on the audit row. Poland has vat_rate_bp 800, so only the supply model shows; a country with both null shows both. Once both are set the form is absent, and no other operations field becomes editable.
States
Demo with two unmet conditions (no Go live) · ready (Go live) · the typed-code dialog · a code that does not match · live, read-only check with what no longer holds, and Back to demo · its confirmation · a role without country.status · flipped toast.
Data drawn
Poland’s zone, 14:00 cutoff, Monday to Saturday and no Sundays from countries.ts; 8 % from prices.data.ts (plan/06 §4, the accountant to confirm). Supply model “Not set” because no answer is recorded. Florists: the synthetic Kwiaciarnia pod Lipą and the two seeded demo florists of admin-partners-*. 20 Oct 2026, 11:40 is a drawn time.
Components
Admin shell, back link, key-value list, data table, status card with the condition list, confirmation dialog with a typed code (spec 012’s high-risk pattern), banner, toast.
Tokens
Conditions ✓ --color-stem, × --color-danger with the words; Back to demo --color-danger; Go live is the one poppy action.
Copy
[slot] copy Every string with a dotted underline is a [slot]: new wording, drawn as a proposal, not yet a key. Spec 012b §7 owns it: messages/admin/en.json under admin.catalogue, admin.media, admin.countries, admin.publish, admin.review; the founder approves the batch. Text without the underline is verbatim from messages/admin/en.json (admin.shell.*, admin.nav.*, admin.roles.*, admin.users.cancel), a registry, or the seed. A [bracketed] value is content we do not have yet (a florist’s bouquet name). Slice A adds no public message key (AC-27). Money through formatMoney in the admin’s en locale; times in the viewer’s admin_profile.time_zone with the zone named.
Scope
Slice A. Accepted defaults (founder 2026-10-20, “all defaults”): §13 Q16 C1 in part, so the country operations editor and the corridor flags are later (after the first sale) and are not drawn as editable here; C2, so Railway is the only publish target and there is no Vercel fallback; C3 declined, so approvals go through the ledger (attest()).
