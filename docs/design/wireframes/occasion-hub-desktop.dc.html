Mother's Day, country by country

Mother's Day is not one day. It is the second Sunday in May in Germany, Italy and the Netherlands, the first Sunday in Spain and Romania, the last Sunday in May in France, and in Poland it is the 26th of May whatever the weekday. If you are sending across a border, the date that matters is the recipient's, and this is the table we keep so that you do not have to.

Every date is computed by occasionDate(rule, year) from that country's own rule and formatted by formatDate in the page's locale — seven countries, seven rules, four different dates, none of them typed. A captioned table with row headers, because this is a reference and a screen reader should be able to walk it. The third column is the country-links-that-exist state: Poland is a link, the other six are text.
The two branches this table has to get rightNot observed. A country with no rule for the occasion is not a row with a blank date — it is absent. The Netherlands keeps no All Saints' Day, so on that hub's table the Netherlands does not appear at all; here it does, because Mother's Day is observed in all seven.Observed, but no date computes. Romania observes Easter on the Orthodox reckoning, which the committed rule set cannot yet express, so occasionDate returns null for it. The Easter hub prints Romania with the date omitted and said to be omitted — never a guessed date, never the Western date quietly reused.
