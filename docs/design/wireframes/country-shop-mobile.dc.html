Purpose
Everything we can make for one destination, at the destination's own all-in price, with the category and occasion doors out of it. It is the first page in the set where a buyer sees money.
URL

Exists
iff the country is published (status === 'live' || guidePublished) and at least one product is deliverable there and the locale is a launch locale. Today that is Poland alone: the other six destinations are demo and have no shop page at any URL. generateStaticParams + dynamicParams = false, so every other slug, segment and casing is a hard 404.
Index
noindex,follow and in no sitemap, for every locale, through spec 007's indexability() — this spec writes no noindex branch of its own. The country-scoped pages become indexable only when corridorState(iso2) === 'live', which needs an active florist; staticNoPartnersProvider answers false for every destination in Phase 0.
Reads
listingView() — the single view model the page, the JSON-LD and the sitemap row all read. Under it: topProductsForPrebuild(iso2, locale, n) for the default order, priceProjection(locale, …) for every price, fromPriceProjection() for the category tiles, countProductsIn() for the tile counts, nextOccasions(iso2, from, 12) for the dated row, and spec 006's media manifest for the photo slots. No cookie is read or written, no request header is varied on, and no response sets Vary.
Currency
The locale's default (en-gb → GBP), never the fo_currency cookie, because cached HTML must be byte-identical for every visitor. The currency chip in the header is inert on this page in Phase 0 (§13 Q9). The prices drawn here are the seeded Polish złoty prices converted through the committed ECB snapshot; the stale-FX state below is what the same page renders when that snapshot ages out.

Before you order

How it reaches Poland

You order from us in your own language and currency. Our florist in the recipient's town makes the bouquet the morning it is delivered and hands it over in person. Nothing crosses a border, so there is no customs form, no paperwork and nothing to pay on arrival.

One short intro, last on the page rather than first, and it is the country block that keeps seven near-identical listings from reading as one page: the authored Poland link, Poland's own occasion dates, its currency and its price column.
What the markup says
SchemaBreadcrumbList mirroring the visible trail, and ItemList of ListItem { position, url, name } in the rendered order — one entry per rendered card, no price, no image, no rating inside it. An ItemList describes an order, not an offer.Forbidden and asserted absent: Product, Offer, AggregateOffer, aggregateRating, review, Event, LocalBusiness. An Offer on a page with no purchase path advertises a transaction we cannot perform.
Parameters?sort= and ?page= are honoured; everything else — ?colour=red, a price band, a session id — is parsed by resolveFacets(), dropped, and contributes only indexable: false with a canonical to this URL. The search-param schema is strict, so there is no infinite parameter space to crawl.
FiltersNone ship in Phase 0 (§13 Q6). The browsing affordance is the category and occasion row above, whose entries are links to real pages — which is what “a facet worth ranking gets an authored path” means.
CachingRendered on the server per request and cached at the edge by full URL (s-maxage=3600, stale-while-revalidate=86400) with tag-keyed data caching beneath, so the per-request work is a projection over already-cached data. No Vary, no Set-Cookie, byte-identical bodies with and without fo_locale, fo_currency and fo_consent.
