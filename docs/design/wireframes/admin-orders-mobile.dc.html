Purpose
The read-only order queue (spec 012 §2.6): newest first, 50 a page, filters by status, destination, delivery date and placed date. Phase 0 AC 4: the mock order appears here within 5 s. Phone (the founder checks from a phone): each order is a row of three lines; filters fold into one button.
URL
/admin/orders?status=&country=&deliveryFrom=&deliveryTo=&placedFrom=&placedTo=&page= (a GET form; ids and codes only).
Index
Never: X-Robots-Tag: noindex, nofollow and Cache-Control: no-store, private on every /admin response, <meta name="robots" content="noindex,nofollow">, Disallow: /admin/, no sitemap, no public link (AC-5, AC-6). No locale prefix. Ids, never names, in URLs.
Permission
orders.view (admin, ops, finance). No action control renders on the list (AC-19).
Reads
Spec 010's listOrdersForAdmin(OrderQueueFilterSchema) → AdminOrderListItemSchema: reference FO-XXXX-XXXX, placed time in the viewer's zone (labelled), delivery date in the destination's zone, city, internal status with the buyer projection, total through formatMoney, florist. No recipient name, phone or street. The poll: GET /admin/api/orders/head every 3 s while visible.
