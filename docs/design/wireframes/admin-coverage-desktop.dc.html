Spec 004 A-founder-2026-10-24a
Item 12: the product × country coverage matrix, the waitlist counts, and the go-live check's core-range item; the core range is the fixed list of 8 to 12 every florist commits to make (founder, 2026-10-24); vendor links check coverage, they never decide the range. New page type.
URL
/admin/coverage (phone: per country, then /admin/coverage/{iso2}).
Index
Never: as every /admin response (spec 012 AC-5, AC-6).
Permission
catalogue.read; without it, 403.
Reads
Active products; the core list; active florists with coverage per country; product-to-florist links; waitlist_signup confirmed counts (no address on screen; exporting addresses is a permissioned, audited action, spec 012). Server-rendered, read-only, no personal data.
Matrix (AC-113)
Rows: the core range first in rank order, then every other active product. Columns: the shop countries and every country with an active florist. Each cell: the number of active florists linked who can make that product there. A core cell under CORE_MIN_FLORISTS = 2 carries a warning (text and icon, never colour alone); a core cell at 0 in a shop country also says the product is hidden from country-less pages. Column heads also show each country's florist count. Filters: all, core only, “core except one country”, countries under 2 florists.
Go-live check
goLivePreflight's item “Core range in {country}”: the florist count per core product there; it fails while any core product has 0 (going live would hide it from every country-less page) and warns where any has fewer than 2. The founder may still flip with spec 012b's typed code, recorded in the audit log (Q-24i).
Data drawn
Synthetic fixture, as on admin-countries-*: Poland has one real florist who makes four core products; the other six countries have none. Waitlist counts are 0 (the table does not exist yet). Product names and SKUs are the catalogue's.
Copy
Admin copy: every dotted-underlined string is a [slot] for messages/admin/en.json (spec 012b §7), proposed wording.
States
Drawn: the matrix with the fixture · the check failing for Poland · phone per-country list. Empty: no active florist anywhere: every cell 0 and every country warned. Error: the admin error page.
