Language popup · desktop 1440 · sweep 2026-10-04 · [internal]
Purpose
The first-visit language choice. Founder, 2026-10-04: “no one should see this page [the / chooser]… they should be shown the site in english.. but a popup appears saying choose your preferred language, english is default and popup is easily closable”. So / answers one fixed permanent redirect to /en for everyone (no IP, no header), and this popup replaces the “Would you rather read this page in English?” strip everywhere.
URL
Any page, first visit only (no fo_locale cookie). Drawn over /en. On /de or /pl the URL's locale is the one marked Current.
Index
Not a page. Nothing in the cached HTML changes: the island renders the dialog after hydration (AC-7/AC-9: byte-identical documents, no Vary).
Reads
Highlight: browser language only (founder, 2026-10-05). The island reads navigator.languages and nothing else: no country, no IP, no /api/geo and no RoPA row for one. This narrows spec 003 §14 A16, which kept A14's country signal, and needs a conforming line in spec 003. Writes fo_locale (essential; consent.cookies.locale.purpose).
Layout
Desktop: native <dialog>, centred card 620 px over --color-scrim. Mobile: a top sheet, about 255 px (30 % of 844), over the chrome only, so the H1, the photograph, the sentence letter and its button stay visible (ruling R10: the brief asked for a bottom sheet; drawn below and why it fails). Four links by native name, lang and hreflang set; each is a real <a> to the same path in that locale.
Closing
× (52 px, top end), Esc, a tap on the dimmed page: all keep the current language and set fo_locale, so it never returns. No timer, no auto-dismiss.
Order
Popup first; the consent sheet (spec 004, consent.*) opens when it closes. Never both on screen.
Removed
LocaleSuggestionBanner* and the banner.* keys (the strip, its square buttons and its square ×). The / chooser artboards are retired (spec 003 §14 A16 clause 1), kept in git history and on the canvas as the record.
Owning spec
003 §14 A14 as amended by A16 (PR 186: four choices, English marked as the default, / a 308 to /en). A16 asks for a mobile bottom sheet ≤ 35 %; this artboard draws the top sheet of audit R10 with the bottom sheet as a state, for the founder to choose. TASK-119.
Copy
[slot L1]–[slot L6], audit Appendix A; the tags “Current” (L3), “Matches your browser” / “Your browser” on 390 (L4) and “Default” (A16 clause 2: “English is marked as the default”; label copy pending founder) are slots too, unmarked inside the buttons to keep them legible. On /en English carries both marks, “Current · Default”; on /de Deutsch is Current and English keeps Default (A16 Reading 1). The marks are words, never colour alone. Native names and “Beta” (common.beta) are real.

Cookies, and what we set them for

We need a few cookies to run the site: the language you chose, your basket, the security of your order.

Everything else is your call, and we set nothing in those groups until you say yes.

The consent sheet waits for the popup and opens only after it closes, so the two never stack. A returning visitor with fo_locale sees neither popup again; the consent sheet follows its own rule (spec 004).
