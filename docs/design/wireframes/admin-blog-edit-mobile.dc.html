Admin · blog post editor · mobile 390 · spec 044 · 2026-10-21 · [internal]
Purpose
Write one post, link it to our own pages, preview it, approve its exact text under your own name, and publish it; later, edit it by revision and publish the change, or take it down (spec 044 §2.3 to §2.6). Desktop: the form on two thirds, the checks or the approval card sticky on the last third, so the next step is always in view. 390: one column, the card after the form, dialogs as bottom sheets. Drawn as the sequence write → link → preview → approve → publish → live → edit → publish changes → unpublish.
URL
/admin/blog/new, /admin/blog/{postId}, preview /admin/blog/{postId}/preview. Ids, never titles or names, in URLs.
Index
Never: X-Robots-Tag: noindex, nofollow and Cache-Control: no-store, private on every /admin response, noindex,nofollow meta, Disallow: /admin/, no public link; Cloudflare bypass. Found by spec 012's enumerated unauthenticated and noindex suites with no hand-kept list (AC-19).
Permission
blog.edit (admin, content): the form, tags, preview. blog.publish (admin, content): Publish post, Publish changes. blog.unpublish and blog.authors: admin only. Approve: spec 012b's translation.attest with en in the user's reviewer_locale and a non-empty display_name. A control the user cannot use is absent, with the reason as text.
Writes
createPost (BlogPostCreateSchema), saveRevision (BlogRevisionSaveSchema), setTags (BlogTagsSchema), attest() for kind blog_post_revision (freezes the revision), publishPost (BlogPublishSchema; requests one spec 012b publish run when the page list changes), publishChanges (BlogPublishChangesSchema; invalidate() once with blog:post:{postId}, blog:{locale}, sitemap), unpublishPost (BlogUnpublishSchema: reason, typed slug). Every form carries the revision's updated_at.
Rules
validateBlogRevision on every save and again at approval and at publish; each refusal beside its field with its rule id: blog/slug-shape, blog/slug-reserved, blog/length, blog/country-tag, blog/link-corridor, blog/link-occasion-or-category, blog/anchor-generic, blog/min-words, blog/distinct, blog/raw-contact, blog/price-literal, blog/scale-claim, blog/relay (pattern id, the word as written and the whole sentence, AC-6), blog/voice, blog/freshness, blog/competitor, blog/claim, blog/allow-stale, blog/h1-in-body. Soft warnings save and show on the card and the preview: title over 60, body over 3,000 words, no ## in a body over 800 words.
States
Writing with hard-rule errors and the checks card · link picker · preview · ready, approve · the approve dialog · approved, publish post · publish run asked, building, live and checked, failed · live with a new draft and the slug locked · publish changes · unpublish dialog · soft warnings · approve absent (no grant) · conflict · allowed sentence and stale entry · refused at publish (a guide vanished) · author withdrawn · publishing off (target none) · Unpublish absent for content.
