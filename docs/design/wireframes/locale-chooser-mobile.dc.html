Locale chooser
Purpose
List the locales and let the visitor choose. It is the root document and it never redirects — not on IP, not on Accept-Language, not ever (ADR-0006).
URL
/ — the only page in the product with no locale prefix.
Index
noindex, follow. A signpost has no query of its own, and the four locale homes are the pages that should rank. follow so the link equity reaches them.
Reads
the locale registry only — code, endonym, whether the locale is indexable. No country data, no prices, no cookies read or written before a choice.
Copy
chooser.heading, chooser.intro, a11y.localeChooser, meta.chooser.* — all present in messages/en.json and quoted verbatim.
Owning spec
003 (shipped)
