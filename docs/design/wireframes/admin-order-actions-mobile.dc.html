Admin · order detail with the action panel · mobile 390 · spec 020a · [internal]
Purpose
The same page on a phone, for the founder answering the no-florist alert at night. The panel becomes a sticky Actions bar at the foot of the page (position: sticky; inset-block-end: 0 in the build; drawn in place under each screen here, as the florist inbox draws its dock) that opens a sheet with the same controls and reasons; tables become card rows. The bar never hides the focused element (WCAG 2.4.11): the page keeps bottom padding equal to the bar's height.
URL
/admin/orders/{orderId} (spec 012's page; the dialogs are native <dialog> elements on it, no URL of their own)
Index
Never: X-Robots-Tag: noindex, nofollow and Cache-Control: no-store, private on every /admin response, the robots meta tag, Disallow: /admin/, no sitemap, no public link (spec 012 AC-5, AC-6). No locale prefix. The order's public_token never appears.
Permission
orders.reroute (admin, ops) · orders.cancel (admin) · orders.refund (admin) · orders.resend (admin, ops); finance and content get no action (spec 020a §13 Q2, AC-1). Each server action calls requirePermission first (AC-2).
Bar
Rendered only when at least one control exists. Its text is the most useful line for the status: the auto-cancel time for no_partner_available, otherwise the count of actions. Finished and demo orders have no bar; their reasons sit in a card under the summary.
Forms
Every form carries a hidden actionId (a uuid minted on the server when the panel renders) and expectedSeq (the highest order_event.seq drawn: 8 on the first screen, 16 on the second). A second submit of one actionId returns the first result with replayed: true; a stale expectedSeq returns ORDER_CHANGED and writes nothing (AC-4, AC-5).
States
No florist with the bar · the sheet open · being made with the lists filled · the panel for each status group · the refunds list in every status.
Money
Every amount through formatMoney from integer minor units with the order's currency, never a float. “Left to refund” is captured minus succeeded, pending and requested refunds (spec 020a §5.2).
Data drawn
Synthetic only. The recipient is tests/fixtures' Anna Kowalska. Florist names are invented fixtures, not shops we work with; payouts (125, 129, 135 zł) are example figures. Times are the viewer's zone, Europe/Tallinn, always named; delivery dates are the destination's (Europe/Warsaw).
