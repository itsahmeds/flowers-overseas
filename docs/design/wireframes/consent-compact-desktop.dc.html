Consent: compact banner and settings from the footer · desktop 1440 · 2026-10-19 · [internal]
Purpose
The founder (2026-10-19): the cookie banner is “way too big”. Ruling “yes yes” to: no banner while the site sets only essential cookies; the footer's “Cookie settings” still opens the settings panel; the banner returns in a compact form when analytics or ads are switched on. This sheet draws all three states 1:1 for the build row.
URL
Every localised page (drawn on /en, the home). The banner is client-only and never indexable content.
Index
Unchanged per page. Nothing here is in the server HTML a crawler reads; the consent island is fetched only after hydration (compact banner) or on activation (today).
Reads
consentSources(process.env): active empty (today: the GA4 id blank, both GA4 rows declared) or non-empty (the id set). fo_consent. src/config/cookies.ts for the folded lists. consent.*, footer.*.
States
§1 today, first visit: no banner. §2 today, “Cookie settings” activated: the panel, no banner behind. §3 analytics on, first visit: the compact corner card. §4 analytics on, Choose: the panel replaces the card. Loading: none drawn; the island loads on activation and the panel appears when it is ready, the link shows no spinner. Error: if the island fails to load, nothing opens and nothing is recorded (as today). With JavaScript off the control does nothing (spec 041 §5).
Measures
Corner card: 420 px wide, inset-inline-end 32 px, inset-block-end 32 px, padding 16 px 18 px, 12 px gap; one line at --text-sm (at most two lines at 420 px); the three answers one row, equal width, 44 px tall, equal prominence (AC-20). About 120 px tall. Panel: the same corner, 420 px, at most 836 px, scrolls inside, Save pinned (19c clause 2). No scrim on desktop.
Behaviour
Compact card: not modal; focus is not moved into it; Esc closes it with no fo_consent. Panel from the footer: focus moves into it (the visitor asked); Esc closes it, records nothing, returns focus to “Cookie settings”. Save writes fo_consent (AC-19 lifetimes) and sends POST /api/consent. With the language bar also pending, see language-bar-desktop.
Copy
