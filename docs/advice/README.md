# Advisor memos

One file per spec or decision the `advisor` agent read before the founder decided:
`YYYY-MM-DD-<spec-or-decision-slug>.md`, at most one page. See `.claude/agents/advisor.md`.

A memo is an opinion, not a decision. The decision lives where it always has: the spec's `Status`
and approval line, or the ADR and `docs/decisions-log.md`. Memos are never edited after the
founder decides. A second opinion on the same subject is a new file.
