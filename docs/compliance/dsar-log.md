# Data subject request log

The dated log of every access, erasure and objection request handled by hand before spec 018 task 5
ships self-service (spec 018 §13 Q16; `docs/runbooks/dsar.md`). The founder reads it **weekly**.

**No personal data here**: this file is committed. A row carries a request number and dates only;
the name, address and order reference stay in the privacy@ email thread of the same number.

The due date is the date received plus **one calendar month** (GDPR Art. 12(3)): received 31 January,
due 28 February (29 in a leap year), never "plus 30 days".

Type: `export`, `erase` or `objection`. Status: `received`, `verified`, `in_progress`,
`waiting_open_orders`, `completed` or `rejected` (the values `privacy_request.status` takes in task 5).
