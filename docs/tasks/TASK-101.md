## Escalations

One dated bullet per escalation: the question, who it went to, the answer or `open`.

- **2026-10-04 E-1: AC-16's "`utm_*`, `gclid` and `fbclid` do not change the cache key" cannot be built on the zone's Free plan** (to: orchestrator → founder; answer: `open`). Cloudflare's cache-rule settings page lists "All query string parameters except" and "No query parameters except" under "Enterprise customers have these additional options for custom Cache Keys". A Free-plan URL-rewrite rule cannot strip only those parameters either: the `matches` regex operator is Business and up, so a query mixing a marketing parameter with a real one (`?page=2&utm_source=x`) cannot be handled. **Not built**; the e2e case is `fixme` naming E-1. Options: (a) amend AC-16 and T-16: such a URL is a separate edge entry (a MISS served from the origin's ISR cache, whose body T-18's byte identity already covers); (b) a rewrite rule that empties the query only when it begins with `utm_`, `gclid` or `fbclid` and holds no `&` (catches the common ad-click URL, misses the rest); (c) Enterprise. Suggested: (a).
- **2026-10-04 E-2: §5.4's rate-limit rule cannot be written as specified on the Free plan** (to: orchestrator; answer: `open`, built as below). Cloudflare's rate-limiting availability table: Free has 1 rule, expression fields "Path, Verified Bot" only (no request method), counting period 10 s, mitigation timeout 10 s. §5.4 row 3 says `starts_with(path,"/api/") or (http.request.method eq "POST")`, 60 per minute, managed challenge then block. **Built:** `(starts_with(http.request.uri.path, "/api/"))`, 10 requests per 10 s per IP (`cf.colo.id`, `ip.src`), Block (429) for 10 s. POSTs to page paths (server actions) are not limited at the edge; the app-level limits of `plan/01` §9 are unchanged. A managed challenge means nothing to an API caller, so Block is the right action anyway. Ask: ratify as a spec 040 §14 amendment.
- **2026-10-04 E-3: Railway says Full (strict) "will not work as intended" behind the orange cloud** (to: orchestrator → founder; answer: `open`, information). - **2026-10-04 E-4: staging is never cached, so T-16's HIT half moves to the cutover** (to: orchestrator; answer: `open`, built in the safe direction).
